# Anti-slop audit 001, 20 November 2026

Mode: AFTER (session override). Kode aplikasi belum diubah.
Arahan: tampilan profesional memakai identitas yang sudah ada, bukan identitas baru.
Design Read: direktori kamar kos untuk calon penyewa, bahasa Indonesia, gaya kartu putih di atas foto dengan aksen indigo `#4f46e5`, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

Prioritas mengikuti tier aturan: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

## HIGH

1. **R-03** Tidak ada satu pun `@media`, jadi tata letak desktop dipaksa ke layar kecil dan tabel di halaman detail serta konfirmasi tidak punya jalur reflow.
   Bukti: `public/css/app.css` seluruhnya 147 baris tanpa media query; `resources/views/rooms/show.blade.php:39-53`, `resources/views/bookings/confirmation.blade.php:34-85`.

2. **R-03** Tombol dan `select` hanya memakai padding 10px tanpa tinggi minimum, sehingga target sentuh di bawah 44px.
   Bukti: `public/css/app.css:88-97`, `resources/views/rooms/index.blade.php:38-54`.

3. **R-25** Border input `#d1d5db` di atas kartu putih hanya 1,47:1, di bawah ambang 3:1 untuk batas komponen interaktif; latar tombol sekunder `#f3f4f6` di atas putih hanya 1,10:1.
   Bukti: `public/css/app.css:103-106,132-137`; dihitung dengan `contrast-check.py`.

4. **R-26** Opsi "Semua Status" mengirim nilai kosong dan controller menerjemahkannya menjadi filter `availability_status = ''`, jadi daftar kamar menjadi kosong.
   Bukti: `resources/views/rooms/index.blade.php:39`, `app/Http/Controllers/RoomController.php:15-17`.

5. **R-26, R-38** Tombol WhatsApp mengirim nama penyewa, nomor kamar, dan tanggal masuk ke nomor hardcode `6281234567890` yang tidak diverifikasi sebagai kontak pengelola.
   Bukti: `resources/views/bookings/confirmation.blade.php:92-105`.

6. **R-27** Daftar kamar hanya memiliki empty state; tidak ada loading state maupun error state saat data gagal dimuat.
   Bukti: `resources/views/rooms/index.blade.php:27-33,83-85`.

## MEDIUM

7. **R-06** Font `Instrument Sans` didefinisikan di `resources/css/app.css` tetapi tidak pernah dimuat oleh keempat halaman, jadi tipografi jatuh ke font default browser.
   Bukti: `resources/css/app.css:6-9`; keempat view memuat `asset('css/app.css')`, bukan `@vite`.

## LOW

8. **R-20** Lebih dari dua puluh kelas yang dipakai view tidak memiliki aturan CSS sama sekali (`container`, `filters`, `room-list`, `room-card`, `room-image`, `room-actions`, `room-summary`, `confirmation-card`, `btn-whatsapp`, `alert-success`, `skip-link`, dan lain-lain), sehingga hierarki visual tidak terbentuk.
   Bukti: perbandingan kelas di `resources/views/{rooms,bookings}/*.blade.php` dengan selektor di `public/css/app.css`.

9. **R-20** Skip link memakai teks Inggris "Skip to main content" di halaman berbahasa Indonesia dan tidak punya gaya fokus karena `.skip-link` tidak didefinisikan, jadi tampil sebagai teks asing di atas kartu.
   Bukti: `resources/views/rooms/index.blade.php:20` dan tiga view lainnya.

10. **R-31** Aturan `body::before` di CSS statis masih berisi literal `{{ asset("images/background.png") }}`, jadi tidak pernah berfungsi dan menduplikasi style inline di setiap view.
    Bukti: `public/css/app.css:11-18`; `resources/views/rooms/index.blade.php:8-17`.

11. **R-38** `welcome.blade.php` adalah scaffold Laravel yang tidak terpakai karena `/` mengarah ke `/kamar`, dan masih berisi tautan ke `login`, `dashboard`, serta `register` yang tidak ada di `routes/web.php`.
    Bukti: `resources/views/welcome.blade.php:21-46`, `routes/web.php:7-16`.

## Batasan

Audit ini berdasarkan inspeksi kode dan penghitungan kontras. Aplikasi belum dijalankan di browser karena database MySQL lokal tidak tersedia, sehingga R-35 (klik-through) belum diverifikasi. Tidak ada perubahan kode aplikasi sampai nomor temuan disetujui.
